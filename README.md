# Assignment Overview

### This repository contains my solutions for Assignment B8A1: Problem Solving with TypeScript.

**The assignment focuses on practicing fundamental TypeScript concepts from Modules 1, 2, and 3, including:**

1. Basic types and optional parameters
2. Union types and type narrowing
3. Readonly tuples
4. Generics and rest parameters
5. Interfaces and array methods
6. Object-Oriented Programming (OOP)
7. Access modifiers and inheritance
8. Asynchronous programming with Promises

All eight coding problems are implemented in a single TypeScript file named `solutions.ts`.
